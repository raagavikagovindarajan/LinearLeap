📏 Vector Magnitude

What is Vector Magnitude?

The magnitude (or length) of a vector is the distance from the origin to the point represented by the vector. It's always a non-negative number.

Formula

The magnitude is calculated using the Pythagorean theorem:

$$|\vec{v}| = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$$

2D Example

Find the magnitude of \(\vec{v} = (3, 4)\):

$$|\vec{v}| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

3D Example

Find the magnitude of \(\vec{u} = (1, 2, 2)\):

$$|\vec{u}| = \sqrt{1^2 + 2^2 + 2^2} = \sqrt{1 + 4 + 4} = \sqrt{9} = 3$$

Another Example

Find the magnitude of \(\vec{w} = (2, -3, 6)\):

$$|\vec{w}| = \sqrt{2^2 + (-3)^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7$$

Unit Vectors

A unit vector is a vector with magnitude 1. Any vector can be converted to a unit vector by dividing by its magnitude:

$$\hat{v} = \frac{\vec{v}}{|\vec{v}|}$$

Creating a Unit Vector

Given \(\vec{v} = (3, 4)\) with magnitude 5:

$$\hat{v} = \frac{(3, 4)}{5} = \left(\frac{3}{5}, \frac{4}{5}\right) = (0.6, 0.8)$$

Verify: \(|\hat{v}| = \sqrt{0.6^2 + 0.8^2} = \sqrt{0.36 + 0.64} = \sqrt{1} = 1\) ✓

Properties

1. Non-negative: \(|\vec{v}| \geq 0\), and \(|\vec{v}| = 0\) only if \(\vec{v} = \vec{0}\)

2. Scalar multiplication: \(|c\vec{v}| = |c| \cdot |\vec{v}|\)

3. Triangle inequality: \(|\vec{u} + \vec{v}| \leq |\vec{u}| + |\vec{v}|\)

4. Dot product relation: \(|\vec{v}|^2 = \vec{v} \cdot \vec{v}\)

Applications

  • Distance: Finding distance between two points
  • Normalization: Creating unit vectors for directions
  • Physics: Calculating speed from velocity vector
  • Computer Graphics: Normalizing normal vectors for lighting

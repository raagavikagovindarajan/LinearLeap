➕ Vector Addition

What is Vector Addition?

Vector addition combines two or more vectors by adding their corresponding components. Geometrically, it represents placing vectors head-to-tail.

Formula

Vectors are added component-by-component:

$$\vec{u} + \vec{v} = (u_1 + v_1, u_2 + v_2, \ldots, u_n + v_n)$$

2D Example

Add \(\vec{u} = (3, 5)\) and \(\vec{v} = (2, -1)\):

$$\vec{u} + \vec{v} = (3 + 2, 5 + (-1)) = (5, 4)$$

3D Example

Add \(\vec{a} = (1, 2, 3)\) and \(\vec{b} = (4, 5, 6)\):

$$\vec{a} + \vec{b} = (1 + 4, 2 + 5, 3 + 6) = (5, 7, 9)$$

Multiple Vectors

Add \(\vec{p} = (1, 0)\), \(\vec{q} = (0, 1)\), and \(\vec{r} = (2, 2)\):

$$\vec{p} + \vec{q} + \vec{r} = (1 + 0 + 2, 0 + 1 + 2) = (3, 3)$$

Geometric Interpretation

Geometrically, vector addition follows the parallelogram law or triangle rule: place the tail of the second vector at the head of the first vector. The sum is the vector from the tail of the first to the head of the second.

Visual Understanding

If you walk 3 meters east, then 4 meters north:

$$\vec{displacement} = (3, 0) + (0, 4) = (3, 4)$$

Your final position is 3 meters east and 4 meters north of where you started!

Properties

1. Commutative: \(\vec{u} + \vec{v} = \vec{v} + \vec{u}\)

2. Associative: \((\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})\)

3. Identity element: \(\vec{v} + \vec{0} = \vec{v}\) (zero vector)

4. Inverse element: \(\vec{v} + (-\vec{v}) = \vec{0}\)

Vector Subtraction

Subtracting a vector is the same as adding its negative:

$$\vec{u} - \vec{v} = \vec{u} + (-\vec{v}) = (u_1 - v_1, u_2 - v_2, \ldots, u_n - v_n)$$

Example

Subtract \(\vec{v} = (2, 3)\) from \(\vec{u} = (5, 8)\):

$$\vec{u} - \vec{v} = (5 - 2, 8 - 3) = (3, 5)$$

Applications

  • Physics: Combining forces, velocities, or displacements
  • Navigation: Finding total displacement from multiple movements
  • Computer Graphics: Translating objects in space
  • Engineering: Analyzing resultant forces on structures

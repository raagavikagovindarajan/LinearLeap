🔀 Linear Transformations

Concept Overview

A linear transformation is a function $T: \mathbb{R}^n \to \mathbb{R}^m$ that preserves vector addition and scalar multiplication. This means it maps lines through the origin to lines through the origin and keeps the grid lines parallel and evenly spaced. Every linear transformation can be represented by multiplication by a matrix $A$, so that $T(\mathbf{x}) = A\mathbf{x}$.

The two defining properties are: additivity — $T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$ — and homogeneity — $T(c\mathbf{u}) = cT(\mathbf{u})$ for any scalar $c$. Common examples include rotations, reflections, scalings, and shear transformations.

Key Formulas

General Matrix Representation:

$$T(\mathbf{x}) = A\mathbf{x}$$

Linearity Conditions:

$$T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}), \qquad T(c\mathbf{u}) = cT(\mathbf{u})$$

Rotation by angle $\theta$ (counterclockwise):

$$R_\theta = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

Scaling matrix (scale $x$ by $a$, $y$ by $b$):

$$S = \begin{pmatrix} a & 0 \\ 0 & b \end{pmatrix}$$

Horizontal shear:

$$H = \begin{pmatrix} 1 & k \\ 0 & 1 \end{pmatrix}$$

Practice Problems

Problem 1 (Easy) — Rotation by 90°

The rotation matrix for $\theta = 90°$ is:

$$R_{90°} = \begin{pmatrix} \cos 90° & -\sin 90° \\ \sin 90° & \cos 90° \end{pmatrix} = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$$

Apply $T$ to the vector $\mathbf{x} = (3, 1)$:

$$T\begin{pmatrix}3\\1\end{pmatrix} = \begin{pmatrix}0 & -1\\1 & 0\end{pmatrix}\begin{pmatrix}3\\1\end{pmatrix}$$

Computing each entry:

$$\text{Row 1: } (0)(3) + (-1)(1) = 0 - 1 = -1$$ $$\text{Row 2: } (1)(3) + (0)(1) = 3 + 0 = 3$$

✅ Answer: $T(3, 1) = (-1, 3)$

Geometrically, rotating $(3,1)$ by $90°$ counterclockwise gives $(-1,3)$.

Problem 2 (Medium) — Scaling Transformation

Let $A = \begin{pmatrix}2 & 0\\0 & 3\end{pmatrix}$ be a scaling matrix that doubles the $x$-component and triples the $y$-component.

Part (a): Apply $T$ to $(1, 4)$:

$$T\begin{pmatrix}1\\4\end{pmatrix} = \begin{pmatrix}2 & 0\\0 & 3\end{pmatrix}\begin{pmatrix}1\\4\end{pmatrix}$$ $$\text{Row 1: } (2)(1) + (0)(4) = 2$$ $$\text{Row 2: } (0)(1) + (3)(4) = 12$$

✅ Answer (a): $T(1, 4) = (2, 12)$

Part (b): Apply $T$ to $(1, 1)$:

$$T\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}2 & 0\\0 & 3\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix}$$ $$\text{Row 1: } (2)(1) + (0)(1) = 2$$ $$\text{Row 2: } (0)(1) + (3)(1) = 3$$

✅ Answer (b): $T(1, 1) = (2, 3)$

Problem 3 (Harder) — Shear Transformation & Unit Square

Let $A = \begin{pmatrix}1 & 1\\0 & 1\end{pmatrix}$ be a horizontal shear matrix.

Part (a): Apply $T$ to $(2, 3)$:

$$T\begin{pmatrix}2\\3\end{pmatrix} = \begin{pmatrix}1 & 1\\0 & 1\end{pmatrix}\begin{pmatrix}2\\3\end{pmatrix}$$ $$\text{Row 1: } (1)(2) + (1)(3) = 2 + 3 = 5$$ $$\text{Row 2: } (0)(2) + (1)(3) = 0 + 3 = 3$$

✅ Answer (a): $T(2, 3) = (5, 3)$

Part (b): Find the image of the four unit square corners $\{(0,0),\,(1,0),\,(0,1),\,(1,1)\}$:

$$T\begin{pmatrix}0\\0\end{pmatrix} = \begin{pmatrix}0+0\\0\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}$$ $$T\begin{pmatrix}1\\0\end{pmatrix} = \begin{pmatrix}1+0\\0\end{pmatrix} = \begin{pmatrix}1\\0\end{pmatrix}$$ $$T\begin{pmatrix}0\\1\end{pmatrix} = \begin{pmatrix}0+1\\1\end{pmatrix} = \begin{pmatrix}1\\1\end{pmatrix}$$ $$T\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}1+1\\1\end{pmatrix} = \begin{pmatrix}2\\1\end{pmatrix}$$

✅ Answer (b): The unit square is mapped to the parallelogram with corners $(0,0)$, $(1,0)$, $(1,1)$, $(2,1)$. The shear slides the top edge to the right while keeping the bottom edge fixed.

Key Properties

1. A linear transformation always maps the zero vector to the zero vector: $T(\mathbf{0}) = \mathbf{0}$.

2. The standard matrix of $T$ is formed by computing $T(\mathbf{e}_1), T(\mathbf{e}_2), \ldots$ and using them as columns: $A = [T(\mathbf{e}_1) \mid T(\mathbf{e}_2) \mid \cdots]$.

3. The composition of two linear transformations $T_1$ and $T_2$ is also linear, with matrix $A_1 A_2$ (note the order: apply $T_2$ first).

4. A linear transformation $T: \mathbb{R}^n \to \mathbb{R}^m$ is one-to-one if and only if $A\mathbf{x} = \mathbf{0}$ has only the trivial solution (i.e., $\text{Null}(A) = \{\mathbf{0}\}$).

5. $T$ is onto $\mathbb{R}^m$ if and only if the columns of $A$ span $\mathbb{R}^m$, i.e., $\text{rank}(A) = m$.

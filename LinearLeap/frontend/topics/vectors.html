📊 Vectors

What is a Vector?

A vector is a mathematical quantity that has both magnitude (size) and direction. Vectors are used to represent physical quantities like velocity, force, or displacement.

Representation

Vectors can be written as ordered lists of numbers, where each number represents a component:

$$\vec{v} = (v_1, v_2, v_3)$$

For example, in 3D space, the vector \(\vec{v} = (3, 4, 5)\) has components along the x, y, and z axes.

Vector Operations

1. Vector Addition

Vectors are added component by component:

$$\vec{u} + \vec{v} = (u_1 + v_1, u_2 + v_2, u_3 + v_3)$$

Example:

$$\vec{u} = (1, 2, 3), \quad \vec{v} = (4, 5, 6)$$ $$\vec{u} + \vec{v} = (5, 7, 9)$$

2. Magnitude (Length)

The magnitude of a vector is its length, calculated using the Pythagorean theorem:

$$|\vec{v}| = \sqrt{v_1^2 + v_2^2 + v_3^2}$$

Example:

$$\vec{v} = (3, 4) \implies |\vec{v}| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$$

3. Dot Product

The dot product of two vectors produces a scalar (single number):

$$\vec{u} \cdot \vec{v} = u_1v_1 + u_2v_2 + u_3v_3$$

Example:

$$\vec{u} = (2, 3), \quad \vec{v} = (4, 5)$$ $$\vec{u} \cdot \vec{v} = 2 \cdot 4 + 3 \cdot 5 = 8 + 15 = 23$$

4. Cross Product

The cross product of two 3D vectors produces another vector perpendicular to both:

$$\vec{i} \times \vec{j} = \vec{k}$$ $$\vec{j} \times \vec{k} = \vec{i}$$ $$\vec{k} \times \vec{i} = \vec{j}$$

Key Applications

Vectors are essential in:

  • Physics: representing forces, velocities, and accelerations
  • Computer Graphics: 3D modeling and transformations
  • Machine Learning: representing data points and features
  • Engineering: analyzing structures and systems
